O problema

Pastas não se organizam sozinhas

Downloads, Documentos e Desktop acumulam arquivos de todos os tipos. Organizar manualmente é lento, repetitivo e arriscado.

01

Tempo perdido

Arrastar arquivo por arquivo para pastas de categoria consome minutos todos os dias e nunca termina.

02

Medo de errar

Uma movimentação errada pode esconder um documento importante. Sem histórico, não há como voltar atrás.

03

Automação frágil

Scripts que apagam ou sobrescrevem arquivos são perigosos. Automação precisa ser previsível, auditável e reversível.

A solução

Tudo o que o CaosZero faz

Uma única CLI, sem dependências externas, com foco em segurança e rastreabilidade.

Organização por categoria

Move arquivos para Documentos, Imagens, Vídeos, Músicas e outras categorias configuráveis por extensão.

Simulação por padrão

O comando organize apenas calcula o plano. Nada é movido sem a opção explícita --apply.

Renomeação em massa

Padrões com {name}, {ext}, {seq:03d}, {date} e {categoria}.

Arquivamento de antigos

Arquivos com mais de N dias vão para Arquivo/AAAA/, sem perder o contexto temporal.

Journal e undo

Cada operação é registrada antes e depois de executada. O undo restaura a última execução com segurança.

Relatórios e diagnóstico

Relatórios em Markdown, CSV e JSON, além de um diagnóstico completo de CPU, memória, disco e permissões.

Arquitetura

Planejar, confirmar, executar, relatar

O planejador nunca altera arquivos. O executor é a única camada com permissão para mover. Essa separação torna a simulação confiável.

  1. 1

    Planejar

    Lê metadados, aplica filtros e calcula destinos sem tocar no disco.

    planner.py
  2. 2

    Confirmar

    Mostra a prévia, avisos e pede confirmação antes de executar.

    cli.py
  3. 3

    Executar

    Move, renomeia ou arquiva e grava cada passo no journal.

    executor.py
  4. 4

    Relatar e desfazer

    Gera MD/CSV/JSON e permite restaurar a execução anterior.

    reporter.py · journal.py
Nenhum arquivo é sobrescrito. Se o destino já existir, o CaosZero gera um nome único: foto.jpg → foto (1).jpg.

Mão na massa

Comece em quatro comandos

Clone o repositório, crie um sandbox e veja o CaosZero em ação sem risco.

1. Criar sandbox

python caoszero.py demo

2. Simular

python caoszero.py organize sandbox_teste

3. Executar e relatar

python caoszero.py organize sandbox_teste --apply --report

4. Desfazer

python caoszero.py undo --latest

Automação

Rode sozinho todos os dias

Scripts para Bash e PowerShell, com agendamento via cron e Agendador de Tarefas. Nada é registrado sem confirmação explícita.

  • Simulação por padrão nos scripts
  • Caminhos absolutos para Python e projeto
  • Relatório automático em cada execução
  • Diagnóstico opcional com --doctor
Ver scripts

Linux / macOS

./scripts/automacao.sh --target ~/Downloads --apply --report
./scripts/agendar_cron.sh --target ~/Downloads --time 09:00 --apply

Windows

.\scripts\automacao.ps1 -Target "$HOME\Downloads" -Apply -Report
.\scripts\agendar_tarefa.ps1 -Target "$HOME\Downloads" -Time "09:00" -Register
